## Decision

What was actually decided and adopted as architecture. State it as fact, in the present tense, as the thing that is now true — not as a proposal.

## Context

What situation led to this decision. What was the state before.

## Alternatives considered

What else was on the table, and why it was not chosen. If this ADR documents an RFC's outcome, this should match that RFC's "Alternatives considered" section, updated with anything learned during review.

## Rationale

Why this decision, specifically, given the alternatives.

## Consequences

What this decision makes easier, harder, or impossible going forward. Include negative consequences honestly — an ADR that only lists benefits is incomplete.

## Related RFC

Link to the RFC that proposed this, if any.

## Architect Sync

Which Architect Sync assessed this, and its verdict.

## Paulo decision

Which decision record authorized this.

## Implementation evidence

Exact commit SHA(s) and the evidence class (`../governance/EVIDENCE_PROVENANCE_MODEL.md`) supporting the claim that this was actually implemented as described.

## Effective version

What Sentinel governance/architecture version this ADR took effect in (`../governance/specifications/VERSIONING_POLICY.md`).

## Supersedes / superseded by

`rule_id`s or prior ADR IDs this replaces, and (once it happens) the ADR that later replaces this one.
