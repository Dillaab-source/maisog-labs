## Workflow for substantial changes
Inspect current screen → name the actual problem (hierarchy, comprehension, composition, typography, interaction, brand drift, accessibility, boredom, complexity) → consult only relevant skills → review as the Design Panel (P0–P3) → preserve what works → don't touch unrelated sections → ask a concise question if a change materially alters brand/structure.

## Critical rule
"More interesting" never means more planets, buildings, glow, particles, glass, cards or animation. First ask what is missing: meaning, interaction, proof, hierarchy, rhythm, contrast or personality.
