# Maisog Labs Brand Kit V3

V3 is the current Maisog Labs brand direction.

## Core identity
**MAISOG LABS — Ideas into systems.**

The orbital wordmark is locked:
- MAISOG serif wordmark
- LABS subline
- thin elliptical orbit
- one star

## V3 website direction
The landing page becomes one immersive cinematic environment combining deep-space systems imagery with disciplined classical architecture. Projects, workflows, case studies, and process content appear as floating modular glass/system cards over the landing canvas.

## Brand balance
- 60% technology / systems
- 25% classical / architectural
- 15% exploration / space

## Core colors
- Deep Space `#0B0F14`
- Warm Ivory `#F7F5EF`
- Steel Blue `#2E4A67`
- Muted Gold `#C9A66B`
- Tech Blue `#6FA7C8`
- Success Green `#38B27D` (status/UI only)

## Recommended typography
- Cormorant Garamond — editorial / major headings
- Inter — navigation / UI / body
- IBM Plex Mono or JetBrains Mono — technical metadata

## Repository structure
- `logos/` — canonical SVG masters
- `design-tokens/` — developer and AI-agent tokens
- `guidelines/` — V3 direction and implementation rules
- `preview/` — visual preview of the approved V3 landing direction

## Important
Do not redesign or substitute the orbital logo unless an intentional brand redesign is approved.
